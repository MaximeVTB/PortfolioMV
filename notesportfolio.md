# Notes de presentation du portfolio

## 1. Vue d'ensemble du site

Ce portfolio est un site vitrine personnel en une seule page, developpe en HTML, CSS, JavaScript et PHP via un fichier principal `index.php`.

Son objectif est de presenter :

- mon profil et mon positionnement de futur developpeur,
- mon parcours scolaire,
- ma specialisation en BTS SIO,
- mes experiences professionnelles,
- mes competences techniques,
- mes certifications,
- mes projets web,
- ma veille technologique,
- une lettre de recommandation,
- un tableau de synthese,
- mes moyens de contact.

Le site adopte une direction visuelle inspiree de l'univers spatial et du jeu video, ce qui renforce mon positionnement autour du developpement de jeux et des experiences numeriques immersives.

## 2. Objectif de presentation

Le site sert de support de communication pour un oral. Il permet de montrer a la fois :

- mon identite professionnelle,
- mon evolution dans le domaine informatique,
- mes acquis techniques,
- mes realisations concretes,
- ma capacite a structurer une presentation claire et moderne.

Le portfolio est organise sous forme de sections accessibles depuis un menu de navigation flottant.

## 4. Choix techniques

Le site repose principalement sur un fichier unique `index.php`, mais il fonctionne essentiellement comme une page front-end enrichie.

Technologies utilisees :

- HTML pour la structure,
- CSS pour les styles personnalises,
- Tailwind CSS via CDN pour la mise en page rapide,
- JavaScript pour les interactions,
- Three.js pour l'arriere-plan anime,
- PHP uniquement comme support de fichier principal a ce stade.

Le projet contient aussi le dossier PHPMailer, mais il n'est pas exploite dans la page actuelle. Cela signifie qu'un systeme d'envoi de mail etait probablement envisage ou pourra etre ajoute plus tard.

## 5. Fonctionnalites interactives du site

Le portfolio ne se contente pas d'afficher du contenu statique. Il integre plusieurs interactions utiles :

- menu de navigation deroulant,
- scroll fluide entre les sections,
- fond anime en Three.js avec etoiles,
- lightbox pour agrandir les certifications,
- fenetres modales pour afficher les PDF,
- bouton de copie de l'adresse mail,
- effets visuels au survol sur les cartes projet.

Ces fonctionnalites montrent ma capacite a travailler l'experience utilisateur et a rendre la presentation plus dynamique.

## 6. Identite visuelle

L'identite visuelle du portfolio est construite autour de plusieurs choix forts :

- theme sombre,
- accents bleus et cyan,
- effet glassmorphism,
- police Space Grotesk,
- inspiration spatiale et futuriste.

Cette direction artistique est coherente avec le positionnement "indie game dev" et donne au site une personnalite claire.

Voici les idees principales a mettre en avant pendant la presentation :

2. Il ne montre pas seulement mes diplomes, mais aussi mes projets, mes stages, mes certifications et ma veille.
3. J'ai cherche a creer un site moderne, visuellement marque, avec une vraie identite.
4. Le site contient plusieurs interactions qui rendent la navigation plus vivante et plus professionnelle.
5. Les projets presentes permettent d'illustrer concretement mes competences techniques.

## 8. Limites actuelles du site

Pour montrer du recul a l'oral, je peux aussi citer quelques limites ou pistes d'amelioration :

- le site est concentre dans un seul gros fichier, ce qui limite la modularite,
- le PHP est tres peu exploite actuellement,
- il n'y a pas de veritable formulaire de contact avec envoi de message,
- certains contenus sont en francais et d'autres en anglais,
- l'un des projets mentionne explicitement l'absence de support mobile,
- une partie du contenu embarque depend de services externes via iframe.

## 9. Axes d'amelioration possibles

Si on me demande comment faire evoluer le site, je peux proposer :

- separer le code en plusieurs fichiers pour mieux maintenir le projet,
- ajouter un vrai back-end de contact avec PHPMailer,
- uniformiser completement la langue du site,
- ameliorer l'accessibilite et le responsive mobile,
- ajouter davantage de details techniques sur chaque projet,
- integrer des filtres ou une chronologie des experiences.

## 10. Conclusion courte pour l'oral

Ce portfolio est a la fois une vitrine personnelle et un support de presentation professionnelle. Il montre mon parcours, mes competences, mes experiences et mes projets dans une interface moderne, dynamique et coherente avec mon orientation vers le developpement web et le jeu video. Il me permet de valoriser a la fois mes acquis techniques, ma creativite et ma capacite a structurer une presentation claire.
